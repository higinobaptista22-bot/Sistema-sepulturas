# Sepultura+

## Sistema Web de Gestão e Rastreabilidade de Sepulturas em Cemitérios

Projeto académico desenvolvido para demonstração de uma solução digital de apoio à gestão, localização, rastreabilidade e conservação de sepulturas.

### Funcionalidades
- Dashboard com indicadores
- Cadastro, edição, pesquisa e remoção de sepulturas
- Mapa visual do cemitério
- Histórico/rastreabilidade
- Gestão ambiental
- Relatórios
- Dados guardados no LocalStorage do navegador
- Design responsivo

### Tecnologias
HTML5, CSS3 e JavaScript.

### Como executar
1. Abra a pasta no Visual Studio Code.
2. Abra `index.html` no navegador.
3. Opcionalmente use a extensão Live Server.

### Observação
Este é um protótipo académico. Os dados apresentados são fictícios e servem apenas para demonstração.

## Estrutura
- `index.html` — dashboard
- `sepulturas.html` — cadastro e consulta
- `mapa.html` — mapa visual
- `rastreabilidade.html` — histórico
- `ambiental.html` — gestão ambiental
- `relatorios.html` — relatórios
- `css/style.css` — estilos
- `js/` — lógica JavaScript
